# AgentMatter Logo

## 概念

五个模块对应 AgentMatter 收录的五类核心资源。模块共同围出一个抽象的 `A`，表示它们不是孤立链接，而是可以组合成 Agent 能力系统的材料。右上角信号绿模块代表正在接入的新组件。

## 文件

- `agentmatter-logo-primary.svg`：浅色背景主 Logo
- `agentmatter-logo-dark.svg`：深色背景 Logo，SVG 本身保持透明
- `agentmatter-logo-monochrome.svg`：单色印刷和低干扰场景
- `agentmatter-mark.svg`：图标、头像和 favicon 源文件

## 品牌色

- Ink Navy：`#0C1635`
- Module Indigo：`#4F46E5`
- Dark-mode Indigo：`#716BFF`
- Signal Lime：`#A3FF12`

## 使用规则

- 导航栏建议高度：主 Logo 32–36 px。
- 图标最小尺寸：16 px；24 px 以下可去掉右上角模块的圆角视觉补偿。
- 安全留白：至少为绿色模块宽度的一半。
- 不旋转、不增加渐变、阴影或发光效果。
- 主字标优先使用 Manrope 750；正式发布前可将字标转换为路径，消除跨平台字体差异。
