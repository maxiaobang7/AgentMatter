# AgentMatter 分类标签与统一资源卡片设计

## 目标

- 分类页使用顶部主题标签快速浏览，标签数量由当前数据动态计算。
- 左侧筛选保留资源形态和适用平台，并按分类增加专属技术维度。
- 顶部主题单选；分类专属技术条件支持同组多选、跨组交集。
- 所有筛选写入 URL，刷新、分享、前进和后退都能还原状态。
- 分类页与搜索页共用效果图中的双列资源卡片。

## 数据结构

资源增加可选 `taxonomy`：一个主主题、最多三个次主题，以及受控的分类专属 facets。标签值使用稳定英文 slug，中文和英文标签由站点词库统一呈现。旧数据库资源缺少 taxonomy 时，站点根据分类、名称、简介、能力和事实执行确定性回退分类，避免资源从目录消失。

## 筛选规则

- `topic` 为单选。
- `host` 与 `subtype` 为单选。
- 分类专属 facet 使用重复查询参数表示多选，例如 `deployment=local&deployment=self-hosted`。
- 同一 facet 内使用 OR；不同 facet、主题、平台和资源形态之间使用 AND。
- 主题数量在忽略当前主题、保留其他条件的前提下动态计算。
- 零结果主题不展示，避免无效点击。

## 页面结构

分类页：标题与搜索 → 主题标签条 → 左侧分类专属筛选 → 已选条件与排序 → 双列卡片。

搜索页：搜索与五类资源标签 → 左侧类型/平台筛选 → 已选条件 → 同一套双列卡片。搜索命中原因作为卡片内的辅助提示，不再使用独立元数据栏。

## 验证

- 单元测试覆盖主题、facet 多选、同组 OR 和跨组 AND。
- 运行 schema 导出、Vitest、ESLint、Next typegen、TypeScript 和生产构建。
- 在中英文、明暗主题、桌面和移动端检查分类页与搜索页。
