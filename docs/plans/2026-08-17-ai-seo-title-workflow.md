# AgentMatter AI SEO 标题工作流

## 目标

让本地 Codex 在生成资源正文时同步生成可审核、可评分、可去重的页面标题与搜索摘要，并由服务器做结构和发布校验。

## 决策

- `Resource.seo` 保存主关键词、无品牌标题、摘要、搜索意图、次关键词、候选标题和选择理由。
- AI 每次生成三个候选标题；最终标题必须包含完整项目名、具体用途、资源类型和清晰搜索意图。
- 页面层统一追加 `| AgentMatter`，避免数据里重复品牌。
- 后台提供搜索结果预览、标题评分和独立 SEO 表单，同时保留完整 JSON 编辑入口。
- 发布 API 检查 Schema 与已有资源标题，库存接口公开 `seoTitle` 供本地选题前去重。
- 没有 `seo` 的历史静态资源继续使用分类模板，逐条更新时再迁移。

## 验收

- AI 生成资源缺少 SEO 字段时无法通过校验。
- 绝对化宣传、社区项目冒充官方、重复品牌名和重复标题无法发布。
- 详情页 HTML title、Open Graph 和 Twitter metadata 使用选中标题。
- 后台修改 SEO 字段时同步写入资源 JSON，并能正常发布和读回。
